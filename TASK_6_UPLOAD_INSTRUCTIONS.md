## Upload through GitHub website

1. Open the repository and select the **main** branch dropdown.
2. Click **View all branches** and then **New branch**. Name it `member-6-qa-devops-reporting`.
3. On the new branch, click **Add file** then **Upload files**.
4. Drag the contents of this Task 6 submission into the upload box. Keep every folder name unchanged.
5. Use this commit message: `test: add QA, CI, Docker and demo documentation`.
6. Click **Commit changes**.
7. Click **Compare & pull request** and create a pull request to `main`.

## Important

Upload the files into the repository root. Do not upload the ZIP itself, `node_modules`, `.env`, or the whole downloaded project archive.
